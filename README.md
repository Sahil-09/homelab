# Homelab

Production-style self-hosted homelab running on Ubuntu Server 24.04.

## Infrastructure

- Docker Engine
- Docker Compose
- Traefik
- Cloudflare Tunnel
- Docker Socket Proxy
- Portainer

## Applications

- Code Server
- Nextcloud
- Immich
- n8n

## Databases

- PostgreSQL
- Redis
- RabbitMQ

## Monitoring

- Grafana
- Prometheus
- Loki
- Uptime Kuma
